# Circular Sound — Rediseño Tiendanube Río

Proyecto de rediseño visual de la tienda Circular Sound.

- Referencia visual: https://circularsound.com/
- Theme funcional: Río, Tiendanube
- Demo visual GitHub Pages: carpeta `docs/` (no es una tienda funcional)
- Paleta: rojo `#FE0000`, negro, blanco
- Tipografía: Poppins

## Política de publicación

La demo pública no contiene credenciales ni el theme privado de Tiendanube.
El código del theme debe versionarse **solo en un repositorio privado** y nunca incluir `.nuvem`, contraseñas, tokens, ni configuraciones FTP.

Un merge en GitHub NO aplica cambios a Tiendanube automáticamente. Para llevar cambios aprobados a la tienda: backup, revisión de diferencias, sincronización mediante CLI FTP autenticado y QA funcional.
